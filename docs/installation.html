Installation et mise à jour

Compatibilité

La compatibilité exacte est déclarée dans appinfo/info.xml. Pour la version 3.4.1, Gestion requiert PHP 8 ou plus récent et utilise la base de données configurée par Nextcloud.

Installation depuis le store

  1. Connectez-vous avec un compte administrateur Nextcloud.

  2. Ouvrez Applications.

  3. Recherchez Gestion dans la catégorie organisation ou bureautique.

  4. Cliquez sur Télécharger et activer.

  5. Ouvrez Gestion et configurez votre première entreprise.

Installation manuelle

Placez l’application dans le répertoire apps/gestion de Nextcloud, puis installez ses dépendances et compilez les ressources :

cd /var/www/nextcloud/apps/gestion
composer install --no-dev --prefer-dist --optimize-autoloader
npm ci
npm run build
sudo -u www-data php /var/www/nextcloud/occ app:enable gestion

Adaptez les chemins et l’utilisateur du serveur web à votre installation.

Mise à jour

  1. Sauvegardez Nextcloud, sa base de données et son répertoire de données.

  2. Mettez à jour l’application depuis le store ou remplacez son code.

  3. Exécutez les commandes de mise à niveau Nextcloud si elles sont demandées.

  4. Contrôlez les migrations :

    sudo -u www-data php occ migrations:status gestion

  5. Ouvrez Gestion et vérifiez une entreprise, un devis et une facture.

Avertissement

Ne modifiez pas directement les tables gestion_*. Les changements de schéma sont appliqués par les migrations Nextcloud et sont conçus pour les différents moteurs de base de données pris en charge.
