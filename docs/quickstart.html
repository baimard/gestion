Démarrage rapide

Ce parcours permet de produire un premier devis, puis une facture.

1. Configurer l’entreprise

  1. Ouvrez Gestion depuis le menu Nextcloud.

  2. Cliquez sur Mon entreprise, puis sur Modifier les informations de l’entreprise courante.

  3. Renseignez au minimum le nom, l’adresse, le code postal, la ville, les mentions légales, la devise et le taux de TVA par défaut.

  4. Pour Factur-X, renseignez également le numéro de TVA, l’IBAN et les identifiants SIRET/SIREN comme expliqué dans Configuration des entreprises.

  5. Choisissez le dossier de sauvegarde dans la navigation latérale.

Les champs éditables sont enregistrés avec la touche Entrée ou lors du changement de sélection, selon le type de champ.

2. Créer un client

  1. Ouvrez Clients.

  2. Cliquez sur Ajouter client.

  3. Complétez la société ou le nom de la personne, l’adresse et les informations fiscales utiles.

3. Créer un produit ou un service

  1. Ouvrez Produits.

  2. Cliquez sur Ajouter produit.

  3. Saisissez une référence, une désignation, le prix unitaire hors taxes et le taux de TVA.

  4. Vérifiez la catégorie de TVA. Pour la catégorie E, vérifiez également le motif d’exonération proposé.

4. Créer le devis

  1. Ouvrez Devis, puis cliquez sur Ajouter devis.

  2. Choisissez la date, le numéro, le client, la version et le statut.

  3. Ouvrez le devis avec l’action correspondante.

  4. Ajoutez les produits, adaptez les quantités et les commentaires.

  5. Enregistrez ou téléchargez le PDF.

5. Créer la facture

  1. Ouvrez Factures, puis cliquez sur Ajouter facture.

  2. Choisissez le devis associé, la date d’échéance et le moyen de paiement.

  3. Ouvrez la facture et contrôlez son contenu.

  4. Générez le PDF classique ou, pour une facture électronique, le PDF Factur-X et/ou son XML.

6. Vérifier puis finaliser

  1. Vérifiez le client, les informations de l’émetteur, les prix, les remises, la TVA et les dates avant de confirmer.

  2. Utilisez Finalize and lock pour finaliser manuellement. La confirmation décrit le caractère définitif de l’action.

  3. Si vous envoyez par e-mail ou à Iopole, l’écran d’envoi rappelle que la finalisation intervient avant la tentative de livraison.

Important

Le verrouillage est définitif et s’applique aux données liées. Un échec d’envoi laisse le document verrouillé, mais autorise une nouvelle tentative. Annuler la confirmation n’envoie rien et ne verrouille rien. Consultez Verrouillage et cycle de vie des documents avant de finaliser votre premier document. Conservez aussi les PDF/XML émis dans Nextcloud Files.
